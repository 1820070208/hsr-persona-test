# 崩铁人格测试 · 24 道题目设计规范

> 本文档是一份自包含的任务书。请严格按照本文档撰写 24 道中文题目，并按第 7 节的 JSON 格式交付。

## 0. 你的任务

你是一位经验丰富的趣味心理测验题目策划。请根据本规范，为一款「崩坏：星穹铁道同人人格测试」网站撰写 24 道题目。要求：轻松好玩、结果稳定可信、答完愿意分享。本规范不需要任何其他背景资料。

## 1. 项目背景

- 玩家答完 24 题后，网站会判定出一个「与他人格最像的星穹铁道角色」。
- 定位是**娱乐向粉丝测评**，不是严肃心理测量。核心诉求：
  1. 3–4 分钟轻松答完；
  2. 结果不随机——同一人隔几天重测，结果应当基本一致；
  3. 结果文案好写好分享。
- **题目中严禁出现任何角色名、派系名、命途名等游戏专有名词**。角色只出现在结果判定阶段（见第 4 节，仅供你理解全局，与出题无关）。

## 3. 四个人格维度

### 轴 A · 社交能量（代码 EI）——你的精力从哪里来？

- **E 群星**：和人相处是充电。热闹之后神采奕奕，闲下来反而想找人。
- **I 深空**：独处是充电。社交愉快但耗电，需要安静时间回血。
- 易错提醒：E ≠ 话多、口才好、社交能力强；I ≠ 社恐、不合群。测的是**精力的来源与消耗方式**。

### 轴 B · 决策罗盘（代码 TF）——做判断时你先听谁的？

- **T 星图**：先看逻辑、利弊、一致性。「这合理吗？」
- **F 心潮**：先看感受、价值、人。「这会让谁难受？」
- 易错提醒：T ≠ 冷酷无情，F ≠ 冲动无脑。两者都可能是聪明人，只是第一反应不同。

### 轴 C · 航行风格（代码 JP）——你怎么对待计划和生活？

- **J 航线**：确定性带来安全感。喜欢提前安排、把事收尾。
- **P 漂流**：留白带来自由感。喜欢见机行事、随机应变。
- 易错提醒：J ≠ 自律上进，P ≠ 拖延懒散。测的是**对不确定性的态度**。

### 轴 D · 目光所向（代码 SN）——你的注意力停在哪？

- **S 大地**：具体的、当下的、五感的、可操作的。
- **N 星海**：抽象的、可能的、联想的、有意义的。
- 易错提醒：S ≠ 无趣死板，N ≠ 不切实际。测的是**注意力的默认落点**。

## 6. 4 道情景题设计

每道情景题 4 个选项，**每个选项固定给一个「轴 + 极」加 1 分**，配对矩阵如下，不得改动：

| 编号 | 场景 | 四个选项分别计分 |
|---|---|---|
| Q21 | 你获得半天空闲，来到一座陌生的城市 | E / I / J / P |
| Q22 | 你所在的团队为一件事争执不下 | T / F / S / N |
| Q23 | 你面对一个没有任何攻略的谜题 | E / I / T / F |
| Q24 | 因为突发状况，你被困在一个地方一整晚 | J / P / S / N |

选项写作要求：

1. 每个选项是一个**具体、有画面感的短句**（20–35 字），像真话，不像选择题选项；
2. 四个选项长度接近（最长的不超过最短的 1.3 倍），吸引力均衡——不要让人一眼看出「正确答案」；
3. 四个选项都要中性可爱，没有褒贬；
4. 场景贴近现实生活，允许出现「列车」「星空」等中性意象词增加氛围，但不得出现专有名词；
5. 每题题干以场景描述结尾，用破折号或问号引出选项。

## 7. 交付格式（JSON）

输出一个合法 JSON 文件（UTF-8，无注释，无多余文本），顶层结构：

```json
{
  "version": "1.0",
  "questions": [ "...24 个对象，顺序为 Q01 到 Q24..." ]
}
```

同意度题对象示例：

```json
{
  "id": "Q01",
  "kind": "likert",
  "axis": "EI",
  "pole": "E",
  "text": "在热闹的聚会里待一晚上，我反而觉得能量更满了。",
  "intent": "人群充电",
  "note": ""
}
```

情景题对象示例（注意四个选项与第 6 节矩阵的对应关系）：

```json
{
  "id": "Q21",
  "kind": "scenario",
  "text": "列车临时停靠在一颗陌生星球，你有整整半天的自由时间——",
  "options": [
    { "text": "……选项一……", "scores": [{ "axis": "EI", "pole": "E" }] },
    { "text": "……选项二……", "scores": [{ "axis": "EI", "pole": "I" }] },
    { "text": "……选项三……", "scores": [{ "axis": "JP", "pole": "J" }] },
    { "text": "……选项四……", "scores": [{ "axis": "JP", "pole": "P" }] }
  ]
}
```

字段说明：

- `axis`：EI / TF / JP / SN 四选一（情景题不用此字段，计分在 options 里）；
- `pole`：题干描述的那一极，取 E/I/T/F/J/P/S/N；
- `intent`：5 字左右的子意图标签，与第 5 节表格一致；
- `note`：给策划的备注，可为空字符串。

## 8. 语言与内容要求

1. 同意度题一律第一人称「我」开头，口语自然，15–25 字；
2. **中性、不评判**：两个方向都不能显得「更好」。反例：「我喜欢帮助别人」（所有人都想同意，测不出差异）；正例：「朋友的坏情绪很容易影响我一整天的状态」；
3. 一道题只测一个意图，禁止复合句（「我喜欢聚会因为能认识新朋友」❌）；
4. 禁止双重否定、反问句；
5. 禁止出现任何游戏专有名词（角色名、命途、派系、地名）；
6. 禁止涉及政治、宗教、疾病、性别刻板印象等敏感内容；
7. 语气整体温暖、轻盈，带一点星空与旅途的浪漫感，但不过度堆砌。

### 附：计分规则（供理解，无需在题目中体现）

- 同意度题：5 档选择映射为 −2…+2 的带符号分，加到该题 `pole` 指向的极上；为负时计入对极。每轴 5 题极性为 3:2 分布，带符号机制保证总权重对称，每轴得分范围 −12…+12（含情景题），以 0 为分界判定极性。
- 情景题：选中的选项给对应「轴 + 极」加 1 分。
